# 응답 저장소 설정 (Google 시트 + Apps Script, 약 5분)

1. Google Drive에서 새 스프레드시트를 만든다. 이름 예: `VISAGE Study 2 responses`.
2. 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 통째로 붙여 넣고 저장한다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**.
   - 설명: `visage v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한: **모든 사용자**(로그인 없이 참여자가 응답을 보낼 수 있어야 함)
5. 권한 승인 창이 뜨면 본인 계정으로 승인한다("확인되지 않은 앱" 경고 → 고급 → 이동).
6. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 `config.js`의 `endpoint`에 넣는다.

시트에는 첫 응답이 들어올 때 `registry`(참여 순번·고지 집단), `rows`(문항별 응답, 긴 형식), `participants`(참여자 요약) 탭이 자동으로 생긴다.

- `Code.gs`를 고친 뒤에는 **배포 관리 → 편집 → 새 버전**으로 다시 배포해야 반영된다(URL은 그대로).
- 테스트는 주소에 `&test=1`을 붙인다. 응답이 `study = pilot-test`로 기록되어 실제 파일럿 순번을 차지하지 않는다(분석 때 `study`로 걸러낸다).
- 파일럿 데이터를 지우고 다시 시작하려면 세 탭을 삭제하면 된다(순번 k가 0부터 다시 매겨진다).
- 같은 pid가 다시 들어오면 같은 순번으로 이어서 하고, 완료한 pid는 재참여가 막힌다.
- 응답 행은 재전송 시 중복될 수 있다. 분석 때 `row_id`로 중복을 제거한다.
